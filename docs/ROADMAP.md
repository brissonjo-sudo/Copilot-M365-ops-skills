# Repository roadmap

## v0.1 — Foundation
- canonical skill;
- references;
- source registry;
- freshness enforcement;
- baseline decision tests;
- CI.

## v0.2 — Cost engine
- machine-readable billing primitives;
- workload calculator;
- regional/contract assumption handling;
- more real-world scenarios.

## v0.3 — Tenant governance
- DSI request templates;
- environment/publishing matrices;
- DLP and lifecycle checklists;
- public-sector deployment patterns.

## v0.4 — Evaluation
- responder/judge evaluation harness;
- regression report artifact;
- model comparison without changing core invariants.

## v0.5 — Distribution
- package for compatible Agent Skill runtimes;
- Copilot/Cowork catalog submission preparation;
- installation documentation.

## v1.0
Release only after the skill passes architecture, billing, freshness and governance test gates across the supported scenarios.
