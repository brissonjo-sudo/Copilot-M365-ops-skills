# Governance and security

## Baseline

Microsoft's Copilot controls framework groups governance into:
- security and governance;
- management controls;
- measurement and reporting.

For enterprise/public-sector deployments, map every solution to these three areas.

## Security checklist

- Microsoft Entra authentication.
- Least-privilege permissions.
- Explicit connector inventory.
- DLP policies for environments/connectors.
- SharePoint permission/oversharing review.
- Purview/compliance requirements where applicable.
- Human approval for sensitive tool calls where supported/required.
- No anonymous publishing unless explicitly justified.
- Separate dev/test/prod environments where operationally appropriate.

## Lifecycle checklist

- named business owner;
- named technical owner;
- maker permissions;
- approval before publication;
- target groups;
- cost policy;
- monitoring;
- change log;
- incident/rollback procedure;
- retirement criteria.

## Public-sector note

Do not treat Microsoft security controls as a substitute for the organization's own legal, records-management, data-protection, procurement, and information-security obligations.
