# Copilot Studio

## First question: which harness?

Copilot Studio now contains materially different execution/billing paths. Always establish the harness before discussing cost.

### Standard harness

Use for many conventional Copilot Studio agents and agent flows.

Billing can be feature-based in Copilot Credits. Qualifying Microsoft 365 Copilot licensed-user scenarios can be zero-rated for documented capabilities.

### GitHub Copilot harness

Use for reasoning-heavy agents/workflows powered by the newer harness.

Microsoft documents usage-based Copilot Credits from build and test through runtime. Do not apply standard-harness inclusion rules to this harness.

## Release cadence

Microsoft states that the Copilot Studio released-versions page is updated weekly on Tuesday and rollout is regional.

Therefore:
- do not infer France availability from US preview availability;
- check the released-versions table and roadmap;
- distinguish preview, targeted release, rollout, and GA.

## Design rule

For each agent record:
- harness;
- environment;
- identity;
- knowledge sources;
- tools/connectors;
- trigger types;
- channels;
- billing policy;
- owner;
- DLP policy;
- approval requirements;
- monitoring and retirement owner.
