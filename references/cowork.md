# Cowork

**Volatility: HIGH.**

Cowork is intended for multistep work that can coordinate skills, integrations and enterprise context. It should not be the default for every simple drafting or lookup task.

## Cost

Microsoft manages Cowork through usage-based Copilot Credits billing. The user-visible `/cost` command can show approximate credits consumed by the current task plus monthly usage/remaining allocation.

Use Cowork when the value of:
- multistep orchestration;
- long-running work;
- cross-tool action;
- richer planning/reasoning

outweighs the usage-based cost.

For simple:
- email drafting;
- single-document summarization;
- straightforward lookup;
- deterministic recurring automation,

compare against ordinary Microsoft 365 Copilot, a standard-harness agent, or a flow first.

## Governance

Before enabling Cowork at scale:
- define eligible users/groups;
- define organization and user spending limits;
- determine which supported usage-based services are covered by policies;
- review whether automatic application to future services is acceptable;
- monitor actual credits from pilot users.
